一、交付了什么
------------------------------------------------------------
1. {{MD_NAME}}
   逐页中文翻译 + 逐页注释的 Markdown 源稿，方便复制到笔记软件。

2. index.html
   离线网页电子书。双击用 Chrome / Edge 打开即可，不需要联网，也不需要起服务器。
   左侧是目录，正文按“第 N 页”排列，每页包含：
   · 【课件中文版】——课件原文的中文翻译
   · 【注释】——这页在说什么 / 为什么 / 怎么用
   · 可选的“原课件图”——该页 PPT 的原画面

3. slides/pNNN.png
   从 PDF 逐页渲染的原图。index.html 会引用这个文件夹，移动网页时请一起移动。

4. {{PDF_OUT}}（打印版）
   A4 排版，把“原课件图 + 译文 + 注释”按页排好，适合打印或在平板上批注。

5. 附录：{{APPENDIX_LIST}}
   复习用的速查表 / 用法速记，放在正文最后。


二、网页怎么用
------------------------------------------------------------
· 左侧目录：按板块折叠。点击页码跳到对应页；当前阅读的页会自动高亮。
· 顶部工具栏：
    显示 / 隐藏注释   只看译文时可以把注释收起来
    显示 / 隐藏原图   对照 PPT 原画面
    深色 / 浅色       夜间阅读
    打印 / 存 PDF     调用浏览器打印
· 搜索框：输入页码、标题或关键词即可过滤页面。
    多个关键词用空格分开，表示“同时包含”（例如：卡诺图 化简）。
    按 Enter 跳到第一个结果；清空搜索后恢复原来的目录展开状态。
    按 / 可以直接聚焦搜索框。
· 键盘：← / → 或 PageUp / PageDown 翻页，j / k 也可以；Esc 关闭放大的图片。
· 手机 / 窄窗口：左上角“目录”按钮打开侧栏；正文自动变成单列。
· 深链接：网址末尾加 #p12 可直接打开第 12 页，例如
    index.html#p12
  附录的深链接是 #p83 这样的连续编号（第 1 页 + 页数）。
· 图片：点击“原课件图”可放大；再点一次或按 Esc 关闭。
· 网址参数（临时覆盖设置，不写入记忆）：
    ?imgs=1        打开时显示原图
    ?notes=0       打开时隐藏注释
    ?theme=dark    深色主题
  例：index.html?imgs=1&notes=0&theme=dark


三、建议的阅读顺序
------------------------------------------------------------
1. 先看某页的【课件中文版】，确认这页在讲什么。
2. 再读【注释】的三段：
   · 这页在说什么——用一两句话抓住必须记住的内容；
   · 为什么 / 直觉——推导、类比、和上一页的联系；
   · 怎么用——做题步骤、常见错误、自检方法。
3. 公式或图密集的页，点“原课件图”对照原画面。
4. 做作业或复习时，直接翻到最后的附录查公式和步骤。
5. 第一遍不必背细节；第二遍只看【注释】的“怎么用”，第三遍用附录自测。


四、打印版说明
------------------------------------------------------------
· 纸张：A4，页边距约 12mm × 11mm；颜色和底纹会保留，请在打印设置里勾选
  “背景图形 / Background graphics”。
· 打印版已包含原课件图、译文和注释；如果只想要文字，可在工作目录重新生成：
    python "{{SKILL_DIR}}/scripts/make_pdf.py" --config courseware.json --no-imgs
· 页数较多时建议双面打印；每页的页码与 PDF 物理页码一致，便于和同学对页。


五、想修改内容怎么办
------------------------------------------------------------
工作目录：{{WORKDIR}}

· 只改某一页：编辑 _out/partNN.md 中对应的“### 第 N 页”，然后依次运行：
    python "{{SKILL_DIR}}/scripts/merge_parts.py" --config courseware.json
    python "{{SKILL_DIR}}/scripts/check_md.py" --config courseware.json
    python "{{SKILL_DIR}}/scripts/build_book.py" --config courseware.json
    python "{{SKILL_DIR}}/scripts/make_pdf.py" --config courseware.json

· 也可以直接改主 Markdown。注意：之后再运行 merge_parts.py 会用 _out/part*.md
  重新生成主文件，直接改的内容会被覆盖。

· 只改标题、分组名、按钮文字：编辑 courseware.json 后重新 build_book.py。
· 网页样式或脚本：在技能目录的 assets/book.css、assets/book.js 中修改后重新构建。
· 校验没通过时先看 check_md.py 的报错行号；常见原因是缺页、卡片标签不在行首、
  表格列数不齐，或用了链接 / 图片 / 斜体 / $公式$ 等会被丢弃的语法。


六、常见问题
------------------------------------------------------------
· 网页打开是空白或按钮没反应？
  请用较新的 Chrome / Edge 打开；不要用 IE。确认 index.html 与 slides 文件夹在一起。
· 原图不显示？
  slides/pNNN.png 被移动或删除了。重新渲染：
    python "{{SKILL_DIR}}/scripts/render_pages.py" --config courseware.json
· 搜索不到某个词？
  搜索按“页面全文”匹配，多个关键词是“与”关系；试试减少关键词或换同义词。
· 打印出来没有底色 / 图？
  打印设置里勾选“背景图形”，并确认没有选“仅黑白”。
· 发现翻译或注释有问题？
  以原课件为准；注释中的“⚠️ 课件笔误”是处理时刻意标出的疑点。
  建议把具体页码和问题记下来，统一修订后重新构建。
