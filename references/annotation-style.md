# 注释写作规范

目标读者：**大二、第一次学这门课、默认零基础**。他们能看懂中文，但不知道术语、
不知道公式为什么长这样、也不知道考试时怎么下手。

注释不是“把译文再说一遍”，而是补上三样课件里没有的东西：**重点、理由、用法**。

## 每页【注释】固定三段

```markdown
**【注释】**

**这页在说什么**
2–4 句。点出这页唯一必须记住的东西；如果是过渡页，就说清它承接什么、引出什么。

**为什么 / 直觉**
推导、类比、假设条件、和上一页的联系。要回答“为什么不是别的样子”。

**怎么用**
做题步骤；新概念给 3–6 行完整小例子；写 1–2 个常见错误和自检方法。
```

三段标题必须逐字使用，方便学生形成稳定预期。不要加第四段小标题；需要补充的内容
并入这三段。

### 这页在说什么

- 先判断这页的“功能”：新概念 / 推导 / 例题 / 对比 / 过渡 / 总结 / 作业。
- 新概念页：一句话定义 + 它解决什么问题。
- 推导页：从哪一步推到哪里，关键假设是什么。
- 例题页：题目在练哪个知识点，解法的骨架是什么。
- 过渡页：不要硬凑三段；50–150 字说明“为什么现在讲这个”即可。
- 禁止空话：“这一页很重要”“大家要认真掌握”“本页介绍了……”都不算内容。

### 为什么 / 直觉

优先级从高到低：

1. **从定义推**：把新规则拆成学生已经会的东西。
2. **类比**：开关、门锁、排队、天平、地图……类比后要说明它在哪里失效。
3. **特例/极端值**：令变量为 0、1、∞，或取边界条件，看规则是否还成立。
4. **与前后页的联系**：上一页的结论在这里被推广/限制/推翻。
5. **历史或工程动机**：只在与理解直接相关时写，不要讲八卦。

要写清“适用条件”。例如公式只在“变量为 0/1”时成立，就要明说，否则学生会套到
连续量上。

### 怎么用

这一段的检验标准：**学生合上讲义，能否照着做出一道题。**

- 给步骤编号（用 `1. 2. 3.` 的单层列表或行内“先…再…最后…”）。
- 新概念第一次出现时，给一个 3–6 行的完整小例子，数字要能算通。
- 写常见错误：符号漏写、边界漏项、单位没换、把“或”当“二选一”等。
- 给自检方法：代回原式、真值表、量纲、极限情形、和已知特例对比。
- 题目页给“解题骨架 + 最终答案”；答案不确定时明确写“待核对”，不要猜。

## 篇幅

| 页面类型 | 【注释】字数 |
|---|---|
| 封面 / 目录 / 章节过渡 / 纯标题 | 50–150 |
| 普通概念页、例题页 | 150–400 |
| 公式密集、图密集、核心推导 | 400–800 |
| 作业说明 / 考试要求 | 100–250 |

宁短勿水。字数不够时，补“为什么”和“怎么用”，不要重复译文。

## 翻译保真

- **全部可见文字都要译**：正文、标题、图注、表头、脚注、页脚、图例、坐标轴标签、
  流程框里的字。图片里的文字看不清就写“图中文字较小，以讲义为准”，不要编。
- **原样保留**：变量名、下标、运算符、数字、单位、表格行列结构、编号、英文缩写。
  术语首次出现写成 `中文（English, 缩写）`，例如 `卡诺图（Karnaugh map, K-map）`。
- **不改课件**：不合并页、不调整顺序、不删“看起来没用”的内容。译文可以顺句，
  但不能改变命题的强弱（“所有”不能译成“有些”，“充分”不能译成“必要”）。
- **补充要显式**：需要加背景才能读懂时，写 `（译者补：…）`，让读者知道这不是原文。
- **术语统一**：开工时建一个 `术语表.md` 放在工作目录根目录（不要放进 `_out/`，
  否则会被 `part*.md` 匹配合并）。每批写作前先读它；新术语先登记再使用。
- **公式写法**：用行内代码，如 `` `F = A·B + A′·C` ``。不要用 `$...$`
  （解析器会丢弃），也不要依赖斜体。
- **强调**：只用 `**粗体**`，不用斜体。课件用颜色/加粗强调的地方，译文用粗体对应。

## 公式与数字必须核验

每个新公式至少做一种检查：

1. **代值**：取 0/1 或简单整数，算两边是否相等。
2. **极限/边界**：变量取 0、1、∞、空集、全集。
3. **量纲/单位**：两边单位是否一致。
4. **小真值表**：2–3 个变量，穷举 4–8 行。
5. **特例对照**：退化后是否回到已知公式。
6. **重新推导**：从定义独立推一遍。

发现不一致时，保留原文并标注：

```markdown
⚠️ 课件笔误：原文 `(A + B)′ = A′ + B′`，按德摩根律应为 `(A + B)′ = A′·B′`。
理由：代入 A=0、B=1，左边 `(0+1)′ = 0`，原文右边 `0′+1′ = 1+0 = 1`，不相等；
更正后的右边 `0′·1′ = 1·0 = 0`，与左边一致。
```

只标**有把握**的笔误；不确定就写“此处符号疑似有误，建议对照教材”，不要武断改公式。
数字、单位、下标、正负号错误尤其要查。

## 图、表、流程

- 只描述图上**真实可见**的标签、连线、箭头、数值；不要根据上下文补出不存在的节点。
- 文字层顺序错乱（`index.json` 的 `needs_vision_pages`）时，以渲染图 `pNNN.png` 为准。
- 扫描页（`scanned_pages`）必须先看图再转写；完全看不清就如实说明，不能跳页。
- 表格译文保持同样的行列数；表头必须译；空单元格保留为空。
- 流程图按“起点 → 判断 → 分支 → 终点”描述，用文字写清每个分支的条件。

## 不同学科的侧重

| 学科 | 注释重点 | 附录建议 |
|---|---|---|
| 数学 / 物理 / 电子 | 条件、推导、符号、单位、边界情形 | 公式表 + 解题步骤 |
| 化学 / 生物 / 医学 | 结构、过程、例外、临床/实验判断 | 术语表 + 流程/鉴别表 |
| 计算机 | 输入输出、复杂度、边界条件、代码语义 | API/语法速查 + 调试清单 |
| 人文 / 社科 | 概念区分、论证结构、文本证据 | 概念对照表 + 论述模板 |
| 法学 | 规则、例外、构成要件、举证责任 | 规则/例外表 + 案例分析步骤 |
| 经济 / 管理 | 假设、模型、变量方向、政策含义 | 模型假设表 + 计算模板 |
| 语言 | 语法点、搭配、语域、常见错误 | 语法/搭配表 + 练习模板 |

没有公式的学科，附录不要硬造公式：改成“术语表 + 时间线/框架图 + 答题模板”。

## 前后页的连续性

- 每批（8–12 页）写作前，先读上一批最后一页的注释，保持术语和记号一致。
- 同一个符号在不同页出现不同含义时，在第二次出现处明确提醒。
- 前面埋的伏笔（“后面会讲”）后面要回收；回收时点一句“这就是第 N 页提到的…”。
- 不要在每页重复同一段背景；第二次以后用“同第 N 页”带过。

## 特殊页面

- **封面**：译标题、副标题、作者/机构、版本；注释说明这份课件覆盖什么、怎么用。
- **目录**：译目录项；注释给一条推荐学习路线，不要逐条解释。
- **章节过渡**：说明上一章遗留的问题和本章要解决什么。
- **作业/实验说明**：译清提交要求、截止时间、评分点；注释给拆解步骤，不替学生做题。
- **总结页**：把本页当成复习清单；注释指出哪几条最容易混。
- **纯图片/扫描页**：先转写再翻译；注释说明“本页为图，文字按图转写”。

## 常见坏写法

| 坏写法 | 问题 | 改法 |
|---|---|---|
| “本页介绍了卡诺图，卡诺图是一种用于化简逻辑函数的图形方法。” | 只是复述定义 | 说清“为什么不用公式硬推”“圈组的规则从哪来” |
| “这个公式很重要，考试常考。” | 空话 | 给代值检验和一个 3 行例题 |
| “显然可得……” | 对零基础不显然 | 补中间一步 |
| 大段复制译文 | 没有增量 | 删掉，换成直觉或用法 |
| 编一个图上没有的节点 | 误导 | 只写看得见的内容 |
| 每页都写“与上一页类似” | 偷懒 | 指出具体相同点和不同点 |
| 用斜体/链接/`$公式$` | 会被解析器丢弃 | 用粗体、纯文本、行内代码 |

## 单页自检

写完一页，问自己：

1. 这页的“一句话重点”是什么？注释第一段是否直接说了？
2. “为什么”是否给了理由，而不是同义反复？
3. “怎么用”是否能让零基础学生照做？有没有小例子和自检？
4. 公式代过值吗？图上信息都来自渲染图吗？
5. 术语和上一批一致吗？有没有出现禁用语法？
6. 有没有把课件没有的内容写进译文（而不是标注为“译者补”）？
