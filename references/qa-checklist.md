# 验收清单

交付前从下往上逐层过。**任何一层失败都要修，不要在最终报告里淡化。**

## Gate 0：静态

```bash
python -m py_compile "<技能目录>/scripts/"*.py
python "<技能目录>/scripts/check_md.py" --config courseware.json
```

- 所有脚本 `--help` 退出码 0。
- `check_md.py` 全量通过（不带 `--allow-partial`），警告逐条看过。
- `courseware.json` 是合法 JSON；`page_count` 等于 PDF 页数。
- 没有残留占位符：`@@...@@`、`__...__`、`TODO`、`（待补）`。

## Gate 1：结构

```bash
python "<技能目录>/scripts/build_book.py" --config courseware.json
python "<技能目录>/scripts/verify_book.py" --config courseware.json --all
```

必须全部通过：

- section 数 = 页数 + 附录数；页面 `id="pN"` 唯一且连续。
- 每页至少一张注释卡；目录项数 ≥ section 数。
- 所有 `href="#pN"` 都有目标；所有 `<img src>` 文件存在。
- 没有模板占位符残留；`<title>` 非空；每节有 `data-label`。
- 桌面 1400px 与移动 430px：无横向溢出，无元素超出视口，侧栏与正文不重叠，
  移动端目录按钮可见。
- DOM 探针：无 JS 报错；搜索有命中、乱词命中 0、清空后全部恢复且分组状态恢复；
  注释开关、原图开关、方向键翻页、`/` 聚焦都正常。
- 无原图模式：按钮隐藏，JS 不报错。

## Gate 2：内容

### 逐页覆盖

- [ ] 每一页都有译文和注释，页码与 PDF 一一对应。
- [ ] 扫描页/纯图页已按渲染图转写，没有跳过，也没有编造。
- [ ] 封面、目录、过渡页、作业页都写了，没有用“略”糊弄。
- [ ] 每页注释都有三段：这页在说什么 / 为什么 / 怎么用。
- [ ] 没有占位式空话；注释过短的页面已重写。
- [ ] 没有把译文原样复制进注释。

### 翻译

- [ ] 正文、图注、表头、脚注、页脚、图例都译了。
- [ ] 变量名、符号、数字、单位、表格结构未改。
- [ ] 术语首次出现有英文/缩写，全文译名一致（对照 `术语表.md`）。
- [ ] 补充内容标了“（译者补：…）”，没有冒充原文。
- [ ] 没有改变命题强弱（所有/有些、充分/必要、可以/必须）。

### 正确性

- [ ] 每个新公式至少做过一种核验（代值/真值表/量纲/极限/重推）。
- [ ] 例题的数字算得通，最终答案自洽。
- [ ] 图上描述的节点、连线、数值都能在原图中看到。
- [ ] 疑似笔误用 `⚠️ 课件笔误` 标注，写了原文、应为、理由；没把握的写“建议对照教材”。

### 附录

- [ ] 有 1–2 篇附录，内容覆盖全篇高频公式/规则/术语。
- [ ] 附录里的每个公式都核验过，和正文一致。
- [ ] 公式少的学科改成了术语表 + 框架/流程 + 答题模板，没有硬凑公式。
- [ ] 附录表格列数一致，能直接打印使用。

## Gate 3：视觉

按全局规则，**布局问题必须看实际渲染，不能只读 CSS 推断**。

生成截图：

```bash
python "<技能目录>/scripts/verify_book.py" --config courseware.json --shots
```

产物在 `<out_dir>/_verify/`：

- `desktop_pNNN.png`：桌面 1400px，抽样页；
- `mobile_pNNN.png`：移动 430px，抽样页；
- `pdf_pNNN.png`：打印版抽样页。

默认抽 first / middle / last。需要额外页面时改 `verify.sample_pages`，例如：

```json
"verify": {"sample_pages": "first,1,20,middle,last"}
```

### 用视觉模型分析

如果环境里有 vision 技能，逐张分析。默认直接使用 DeepSeek 识图：

```bash
python ~/.claude/skills/vision/vision.py --provider deepseek \
  "_verify/desktop_p001.png" \
  "分析布局问题：对齐、间距、溢出、留白、截断、空白区域、遮挡、对比度"
```

`vision.py` 会自动优先选 `deepseek`（读取 `DEEPSEEK_API_KEY`，缺省时回退到
`ANTHROPIC_AUTH_TOKEN`）。需要换模型时才加 `--provider qwen` 或
`--provider openai`。输出乱码时按 GBK 解码后再看。
vision 不可用（缺少 API key、401、网络失败）时：

1. 不要反复重试到超时；
2. 直接查看截图，并依赖 DOM/几何断言；
3. 在最终报告里明确写“**未完成模型化视觉分析**，仅做了截图人工检查与几何断言”，
   不得写“视觉上完全正常”。

### 每张截图看什么

- 顶栏按钮是否换行、溢出、压住正文；长标题是否截断。
- 侧栏分组名、页码、描述是否对齐；折叠箭头是否错位。
- 正文卡片间距是否一致；注释与译文是否有明显层级差。
- 公式/代码块是否横向溢出；长表格是否被裁切；宽表在移动端是否可横向滚动。
- 图片是否变形、模糊、超出卡片；灯箱是否遮住关闭入口。
- 移动端：目录按钮是否可见；侧栏展开后是否能关闭；正文是否单列。
- 附录：页码标签是否显示成“第 83 页”（错误）而不是“附录 A”。
- 深色模式：文字对比度是否足够；代码块、表格边框是否可见。
- 打印预览：分页是否切断标题/表格；背景色是否保留；页脚是否重复。

### 建议额外截的图

- 最长标题的一页；
- 最大的表格/公式块；
- 第一篇附录；
- 深色模式一页；
- 移动端展开目录的状态。

`verify_book.py` 默认不截这些，需要时用 `sample_pages` 指定页码，或手工用
Chrome 打开 `index.html#pN` 截图。

## Gate 4：PDF

```bash
python "<技能目录>/scripts/make_pdf.py" --config courseware.json
python "<技能目录>/scripts/verify_book.py" --config courseware.json --pdf-check
```

- [ ] 首页尺寸是 A4（595×842 pt，允许 ±3）。
- [ ] 页数 ≥ section 数；没有整页空白。
- [ ] 抽样页能提取到中文文字（不是整页图片）。
- [ ] 原课件图已打印（默认模式）；图没有被裁切。
- [ ] 表格、代码块没有跨页断裂；标题没有孤行。
- [ ] 背景色/底纹保留（打印设置勾选背景图形）。
- [ ] 文件大小合理（82 页含图约 10–15 MB；异常大时降 DPI 或检查重复图）。

如果 PDF 里没有图，检查：

1. 是否用了 `--no-imgs`；
2. `slides/` 是否存在；
3. 临时 HTML 是否被正确生成（`loading="eager"`）；
4. Chrome 超时是否太短。

## Gate 5：成品与文档

- [ ] `index.html` 双击可离线打开，不需要服务器。
- [ ] `slides/` 与 `index.html` 同目录；移动整个文件夹后仍正常。
- [ ] `使用说明.txt` 已按实际标题、页数、附录名、路径填写，没有 `{{...}}` 残留。
- [ ] 主 Markdown 可直接阅读；目录只有一份。
- [ ] `_out/`、`_extract/`、`_verify/` 保留，便于后续修改。
- [ ] 最终报告列出：页数、附录数、文件路径、通过的检查、已知限制。

## 按课件规模调整

| 页数 | 策略 |
|---|---|
| 1–5 | 一次写完；仍要跑全量校验和截图 |
| 6–20 | 分 2 批，每批 8–12 页 |
| 21–100 | 分 8–12 页一批；每批后 `check_md --allow-partial`；先建术语表 |
| 100+ | 先按章建 `sections`；每批 8–10 页；中途合并一次做结构冒烟测试 |

## 最终报告模板

```
已完成《标题》中文学习包：
- 原文：xxx.pdf，共 N 页
- 翻译与注释：N 页，附录 M 篇
- 成品：<out_dir>/index.html（离线）、<pdf>
- 校验：check_md 通过；verify_book --all 通过（结构/DOM/布局/PDF）
- 视觉：已用 vision 分析 K 张截图 / 未完成模型化视觉分析（原因），已人工看截图
- 已知限制：……
```
