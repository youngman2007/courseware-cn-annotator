# Markdown 契约

电子书构建器是手写的、只用标准库的小解析器，**不是通用 Markdown**。它认识的内容
有限，不认识的内容会被忽略、压平或原样显示。写稿前先看完这一页；`check_md.py`
会拦住绝大多数问题。

## 页面骨架

```markdown
### 第 1 页 · 逻辑门

**【课件中文版】**

**第 1 章　逻辑门**

与门（AND）、或门（OR）、非门（NOT）是三种基本逻辑门。

**【注释】**

**这页在说什么**
这一页把“逻辑”落到三种最基本的电路元件上。

**为什么 / 直觉**
与门像两个串联开关，两个都闭合灯才亮。

**怎么用**
先判断题目要“同时满足”还是“满足一个即可”，再选门。

---

### 第 2 页 · 真值表

**【课件中文版】**

……
```

硬性规则：

1. 页面标题必须是行首的 `### 第 N 页 · 标题`。`###` 不能缩进。
   - `N` 从 1 开始**连续**，不能跳号，不能重复，最大值等于 PDF 物理页数。
   - `·` 可省略，但建议保留；标题不要为空，否则侧栏只有页码。
2. 每页第一张卡必须是 `**【课件中文版】**`，第二张必须是 `**【注释】**`。
   标签必须**独占一行、从第 1 列开始**，前后不能有别的内容。
3. 卡片标签可以改（配置 `labels.translation` / `labels.notes`），但正文与配置必须一致。
4. 页与页之间用 `---` 分隔；`merge_parts.py` 依赖它拼接分批文件。
5. 第一个页面标题之前只能放引言/说明；目录由脚本自动插入。

## 附录

```markdown
### 附录 A · 三种基本门速查

**【速查表】**

| 门 | 表达式 | 口诀 |
|---|---|---|
| 与门 AND | `F = A·B` | 全 1 才 1 |
| 或门 OR | `F = A + B` | 有 1 就 1 |
```

- 编号只接受字母或数字：`A`、`B`、`C`、`1`。**`附录一` 不匹配**，会报“不是页面/附录标题”。
- 显示为“附录 A”，内部编号自动排到 `页数 + 1`，深链接是 `#p83` 这类连续值。
- 附录卡片标签自由：`【速查表】`、`【用法速记】`、`【术语表】` 都可以。
- 附录至少一张卡；不要求两张。
- 附录**不会**配课件原图。
- `appendix: true` 时最终稿至少要有一篇附录；分批校验可用 `--allow-partial` 暂时跳过。

## 支持的语法

| 语法 | 写法 | 渲染结果 |
|---|---|---|
| 段落 | 连续非空行 | 一个 `<p>`，行间 `<br>` |
| 粗体 | `**文字**` | `<strong>`；必须在同一行闭合 |
| 行内代码 | `` `F = A·B` `` | `<code>`；不能包含反引号 |
| 围栏代码 | ` ``` ` 开头和结尾 | `<pre><code>`；语言名不参与高亮 |
| 四级标题 | `#### 小标题` | `<h5>`；页面内小标题用它 |
| 无序列表 | `- 项` 或 `* 项` | `<ul><li>` |
| 有序列表 | `1. 项` | `<ol><li>` |
| 嵌套列表 | 行首 2 个空格 + 标记 | 只支持**一层**嵌套 |
| 表格 | 表头行 + `|---|` + 数据行 | `<table>` |
| 引用 | `> 文字` | `<blockquote>` |
| 分隔线 | `---` | 被移除（只用于分隔页面/分批） |

补充说明：

- **段落换行**：同一段里的换行会变成 `<br>`，所以不要把一句话拆成很多短行；
  分段请空一行。
- **列表项只能一行**。列表项下面续写普通段落会生成不合法结构；请把说明写进同一行，
  或另起一段。
- **列表结束**：空行、表格、代码块、标题都会结束列表。列表前不要缩进。
- **表格**：必须有分隔行；每行列数必须与表头一致（`check_md.py` 会报错）。
  单元格里不能出现 `|`，包括行内代码里的 `|`。表格内可以用粗体和行内代码。
- **行内代码优先于粗体**：`` **`x`** `` 可用，但不要嵌套反引号。
- **标题层级**：页面标题占用了 `###`；卡片内请用 `####` 或更小。`#`、`##` 也能渲染，
  但容易和页面标题混淆，不推荐。
- **HTML 转义**：`<`、`>`、`&` 会自动转义；不要写原始 HTML 标签。
- **自动目录**：`<!-- AUTO-TOC:START -->` 与 `<!-- AUTO-TOC:END -->` 之间的内容由脚本维护，
  不要手改；重复运行 `merge_parts.py` 会替换而不是追加。

## 禁用语法

以下写法不会被解析成预期效果，`check_md.py` 会报错或警告：

| 写法 | 后果 | 替代 |
|---|---|---|
| `[文字](链接)` | 链接语法不解析，原样显示/被丢弃 | 写纯文本网址或说明 |
| `![说明](图片.png)` | 图片不解析；原图由 `slides/` 自动插入 | 删除，改用“原课件图”按钮 |
| `*斜体*` / `_斜体_` | 星号原样显示；下划线不解析 | `**粗体**` 或纯文本 |
| `~~删除线~~` | 原样显示 | 纯文本 |
| `<b>HTML</b>` | 被转义成可见文本 | 用 Markdown 粗体 |
| `$a+b$` / `$$…$$` | 不解析，原样显示 | 行内代码 `` `a+b` `` |
| 反斜杠转义 `\*` | 不解析 | 直接写字符 |
| 表格里出现 `\|` | 列会被切断 | 改写措辞，避免竖线 |
| 正文中的 `**【…】**` | 不会切卡，可能吞掉后续内容 | 标签独占一行 |

## 卡片切分细节

- 切分只看**行首独立的标签行** `**【标签】**`。标签前有空格、标签后同一行有文字，
  都不会被识别。
- 第一张卡之前如果还有正文，构建时会并入第一张卡（`check_md.py` 给警告）。
  建议把引言移进卡片，结构更清楚。
- 页面可以有第三张及以后的卡；它们会渲染成注释样式。一般不需要。
- 标签内容不能为空：`**【】**` 不匹配。
- `**【注释】**` 在页面中间出现会把后面的内容切成新卡；正文里不要出现这种字样。

## 页码与页数

- 页码是 **PDF 物理页**（第 1 页就是 PDF 的第 1 页），不是课件印刷页码。
- 封面、目录、空白页也算页，必须各写一节；空白页可以只写一句说明。
- `page_count` 必须等于 PDF 页数；`build_book.py` 发现 Markdown 页数不符会直接失败。
- 附录不计入 `page_count`。
- 合并后附录会被重新编号；不要在 Markdown 里手写 `#p83` 这类链接（链接语法本来也不支持）。

## 一个可直接通过校验的最小样例

```markdown
### 第 1 页 · 示例

**【课件中文版】**

这是课件的译文。

**【注释】**

**这页在说什么**
这是示例页。

**为什么 / 直觉**
因为它用于演示格式。

**怎么用**
照着这个结构写每一页。

---

### 附录 A · 速查

**【速查表】**

| 项目 | 内容 |
|---|---|
| 页面标题 | `### 第 N 页 · 标题` |
| 卡片标签 | 行首独立一行 |
```

## 出错时怎么读报错

`check_md.py` 的行号是**主 Markdown 的全文行号**（从文件第 1 行算起），可以直接跳转。

常见报错与修法：

| 报错 | 原因 | 修法 |
|---|---|---|
| `只有 1 张卡，应有【课件中文版】和【注释】` | 标签写错/没独占一行 | 检查标签前后有无空格或文字 |
| `第一张卡标签是【注释】，应为【课件中文版】` | 两张卡顺序反了 | 对调 |
| `缺少页面：[7]` | 跳号或漏写 | 补第 7 页；分批时用 `--allow-partial` |
| `页码重复：[3]` | 复制粘贴没改页码 | 改成正确页码 |
| `### … 不是页面/附录标题` | 页面内用了三级标题 | 改成 `####` |
| `表格列数 3 ≠ 表头 4` | 少写/多写一列 | 补齐或删掉多余 `|` |
| `链接语法会被丢弃` | 用了 `[]()` | 改成纯文本 |
| `$…$ 数学语法会被丢弃` | 用了 LaTeX | 改成行内代码 |
| `配置要求附录，但没有找到` | 忘记写附录 | 补 `### 附录 A · …` |
| `注释内容过短` | 占位没写 | 补全三段注释 |
| `第一张卡之前有正文` | 引言写在了标签外 | 移进第一张卡 |
